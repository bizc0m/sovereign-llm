# Sovereign LLM 🦅

**Un LLM vraiment souverain. Pas de VC. Pas de board. Pas de bullshit.**

On construit un LLM open source, financé par une communauté autonome (LA MEUTE), entraîné en toute transparence. Pas contrôlé par OpenAI, Google, Anthropic ou aucun corporate agenda.

## Philosophie

- **Pas de VC** — notre agenda, nos décisions
- **Pas de fausse promesse** — on montre tout, on cache rien
- **Pas de corporate overlord** — le modèle appartient à la communauté
- **Bootstrappé** — petit budget, grande ambition

## Stack

- PyTorch
- Fine-tuning sur base open source
- Compute décentralisé (Akash / Bittensor / donations)
- Dataset curation communautaire
